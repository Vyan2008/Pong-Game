# Pong-Game
The goal of this project is to recreate Pong in Godot Engine. The MVP scope is a simple Pong game that allows for the player to move the user paddle and face against a self-moving computer paddle. Both paddles collide with the ball and the speed of the ball increases after each collision. The score of the computer and player is tracked and when either reaches a score of 10, the game ends and the winner is announced. Future plans are to add an easy, medium, hard, and hardcore difficulty and a reversed controls and random speed game mode. The program will be coded in GDScript and free use assets and sounds with be implemented later to make the game more polished.
